Softer and rounder, same signal red

The primary colour is the original signal red. Main buttons, the Start button, the calorie ring and the PR badge use the same red-to-ember gradient as the photo filter. Cards and tiles are rounded on a soft paper ground. Type, mono labels, the lockup and the photo filter stay from the design system. Figures are examples. Icons are from Tabler Icons, a free open-source set (MIT licence).
